# DVP Safe — экспериментальная сборка

Прокси DLL для Discord, адаптированные на основе проектов runetfreedom/discord-voice-proxy и runetfreedom/force-proxy (GPL-3.0). Неофициальный форк. **Не проходил проверки сборки Windows и запуска Discord**.

## Важные ограничения

- В первой версии асинхронные сетевые вызовы на SOCKS5-ассоциированных UDP-сокетах **отклоняются**. Это предотвращает опасное преждевременное освобождение буфера, но голосовой чат может не работать.
- Отключён старый перехват CreateProcessW: после очередного обновления Discord, возможно, потребуется повторная установка DLL в новую версию `app-*`.
- Сборка PE и проверка экспортов не доказывают совместимость с Discord.
- Не заменяйте системный `DWrite.dll` в папках Windows.

## Проверка с безопасным режимом

Пусть друг полностью закроет Discord. Запустит PowerShell в папке с распакованными DLL и вызовет:

```powershell
.\Install-DVPSafe.ps1 -DWriteDll (Join-Path $PWD 'DWrite.dll') -ProxyDll (Join-Path $PWD 'force-proxy-safe.dll') -ProxyAddress '127.0.0.1' -ProxyPort 10808
```

Заменить порт на свой SOCKS5. Затем в `%LOCALAPPDATA%\Discord\app-*\proxy.txt` дописать строку `DVP_SAFE_MODE=1`, проверить запуск Discord. После закрытия Discord убрать эту строку и попробовать прокси. Лог находится в `%LOCALAPPDATA%\DVP-Safe\loader.log`.

При сбоях запустить `Disable-DVPSafe.ps1` при закрытом Discord. Скрипт не возвращает автоматически старую проблемную DLL.

Вложенный `DVP-Safe-Source.zip` содержит исходники этого форка, собранную версию сетевого компонента и используемые скрипты. Оригинальные лицензии находятся в архивах исходников.
